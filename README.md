The **Drug Intelligence Console (DIC)** is a high-performance, stateless API built with FastAPI. It serves as the core intelligence engine for medical applications like **MedCheck**. 

By pre-compiling massive FDA and RxNorm regulatory datasets into in-memory hash registries, the DIC can perform deterministic clinical reasoning, flag adverse drug-drug interactions (DDIs), and calculate renal/hepatic dosage adjustments in milliseconds.

---

## 🧠 Core Features

* **Lightning-Fast Reasoning:** Avoids heavy SQL joins by utilizing a pre-compiled JSON registry loaded directly into memory, enabling `O(1)` time complexity for interaction lookups.
* **Biomarker-Aware Analysis:** The `/analyze` engine doesn't just check drugs against drugs; it factors in patient contexts such as `renal_clearance` and `hepatic_impairment` to surface dynamic contraindications.
* **Deterministic Traceability:** Every clinical warning outputted by the console provides a direct evidence trace back to official OpenFDA or RxNorm canonical IDs, preventing "AI hallucination" in critical healthcare contexts.
* **Integrated Admin Frontend:** Ships with an embedded visual Admin Console served at the root `GET /` to intuitively debug requests and visually monitor the clinical ledger.

## 🔌 API Endpoints

The API is mounted at the `/api/v1` prefix. All endpoints return standardized JSON payloads.

### 1. Clinical Analysis (`POST /api/v1/analyze`)
**Purpose:** Analyzes a full prescription against a patient's biological context.
**Payload:**
```json
{
  "medications": [
    { "id": "DIC_DRUG_ATORVASTATIN", "name": "Atorvastatin" },
    { "id": "DIC_DRUG_CLARITHROMYCIN", "name": "Clarithromycin" }
  ],
  "patient": {
    "age": 65,
    "renal_clearance": "NORMAL",
    "hepatic_impairment": "MILD"
  }
}
```
**Response:** Returns a complete execution trace containing the `clinical_report`, interaction severity, and evidence citations.

### 2. Quick DDI Check (`POST /api/v1/interactions`)
**Purpose:** Extremely fast, direct check for interactions between canonical medication IDs.
**Payload:** `{"medication_ids": ["DIC_DRUG_1", "DIC_DRUG_2"]}`

### 3. Registry Search (`GET /api/v1/drugs/search?q={query}`)
**Purpose:** Fuzzy-searches the in-memory registry for medications by their brand or generic name.

### 4. Health & Telemetry
- `GET /health` - System health check
- `GET /ready` - Registry load readiness
- `GET /metrics` - Performance and latency metrics
- `GET /version` - Current API build version

## 🛠️ Local Setup & Deployment

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Harsha-E/Drug-Intelligence-Console.git
   cd Drug-Intelligence-Console
   ```

2. **Create a virtual environment & install dependencies:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Run the server:**
   ```bash
   uvicorn app:app --reload
   ```
   *The API will be available at `http://127.0.0.1:8000`.*
   *The autogenerated Swagger UI docs are at `http://127.0.0.1:8000/docs`.*
